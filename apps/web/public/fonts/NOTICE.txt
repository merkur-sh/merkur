Modification notice
-------------------

The `.ttf` files in this directory are NOT the upstream binaries. They were
re-emitted with `hb-subset` to drop tables that the terminal renderer never
reads (PostScript glyph names, layout/positioning, and hinting). No codepoint
was removed and no glyph outline was altered: the mapped character set and the
font metrics are byte-identical to upstream.

`SUBSET.json` in this directory records the upstream version, the exact command,
and the sha256 of every file before and after, so the transformation can be
reproduced or reversed.
