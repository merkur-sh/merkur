A code block names its file and marks one line:

```rust file=example/diff.rs mark=5
pub fn diff(grid: &Grid, seen: &RowHashes) -> Update {
    let rows = grid
        .rows()
        .enumerate()
        .filter(|(i, row)| seen.get(*i) != Some(row.hash()))
        .map(|(i, row)| RowPatch::new(i as u16, row.cells()))
        .collect();
    Update { version: grid.version(), rows }
}
```
