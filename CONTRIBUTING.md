# Contributing

Merkur is licensed under the AGPL-3.0, except for `packages/logger`, which is under the Apache
License 2.0. See [`NOTICE`](NOTICE).

Before a pull request can be merged, its author signs the [Contributor License Agreement](CLA.md).
The CLA check on the pull request posts the instructions: reply with the sentence it quotes. You
sign once; it covers every later contribution.

The CLA lets the maintainer license contributions under any of the repository's licenses, move
code between them, and offer [commercial licenses](COMMERCIAL-LICENSING.md). You keep the
copyright in your contribution. The Merkur name and logo are covered by the
[trademark policy](TRADEMARK.md), not by the software licenses.

Development setup, style, and verification are in [`AGENTS.md`](AGENTS.md) and the
[README](README.md#development).
